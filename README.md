# Every Second Counts ⏳

> **Minimalist real-time age & life telemetry New Tab extension for Chrome and Firefox.**

---

## ⚡ Features

* **Precision Real-Time Age**: Calculates age down to **8 decimal places** updated continuously at **60 FPS** (`requestAnimationFrame`) using the tropical year constant (`365.242199` days/year).
* **Zero Jitter Typography**: Tabular monospace numerals guarantee rock-steady positioning without layout shift.
* **True Black Aesthetic**: Pure `#000000` background with crisp white typography and subtle red accent styling.
* **Year Progress & Milestones**: Live progress bar showing percentage of current year completed + live countdown timer to your next birthday.
* **Life Perspective (80Y)**: Tracks total days, hours, and weeks lived vs. an 80-year horizon.
* **Biological Telemetry**: Real-time estimated heartbeats and breaths taken over your lifetime.
* **Daily Focus**: Integrated minimalist daily intent field saved locally.
* **Offline First**: Zero external dependencies, libraries, or CDNs.

---

## 🚀 Installation

### Google Chrome / Edge / Brave
1. Clone or download this repository.
2. Go to `chrome://extensions` and enable **Developer Mode**.
3. Click **Load unpacked** and select the extension directory.
4. Open a new tab (`Ctrl + T`).

### Mozilla Firefox
1. Go to `about:debugging#/runtime/this-firefox`.
2. Click **Load Temporary Add-on...**.
3. Select `manifest.json`.
4. Open a new tab (`Ctrl + T`).
